# Reference compositions

Finished poster renders, one per reference composition listed in `../manifest.json`. These are the "ground truth" visuals — when you add new slot variants or palettes, render a new composition here so the system has a visual benchmark.

## Conventions

- Filename: `<composition-name>.png` matching the `name` in `manifest.json` → `reference_compositions[]`.
- Export at @1x of the source canvas (4085 × 7262) or scaled down to longest-edge 2048 if file size matters.
