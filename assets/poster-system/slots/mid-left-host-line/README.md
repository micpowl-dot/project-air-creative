# Slot: `mid-left/host-line`

**Purpose:** Host/speaker caption below the title.
**Color role:** `anchor-dark`
**Format:** Outlined SVG text OR live text.
**Naming:** `host-<first-last>.svg` — e.g. `host-maya-smith.svg`

The prefix "Host" is constant; the name is the variable. Keep the prefix in the variant so n8n can swap the whole line.
