# Slot: `upper-left/date`

**Purpose:** Event date display type, upper-left.
**Color roles:** `anchor-dark` (main) + `accent-primary` (one digit/letter accented)
**Format:** Outlined SVG text (so font is locked in) OR live text with declared font.
**Naming:** `<event-slug>-<date-slug>.svg` — e.g. `june-9-2026.svg`, `oct-15-2026.svg`

## Accent rule
Pick one digit or letter pair to render in `accent-primary`. On the reference poster the "26" of 2026 is accented.

## Current variants
- `june-9-2026.svg` — reference

## Ideas for future variants
- One file per event date you need to render.
- A `multi-day` variant (e.g., "June 9–11, 2026") with the day range as the accent.
