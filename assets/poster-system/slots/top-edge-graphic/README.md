# Slot: `top-edge/graphic`

**Purpose:** Decorative banner across the top edge of the poster.
**Color roles used:** `anchor-dark`, `anchor-light`, `accent-primary`, `dominant`
**Format:** SVG, full-width of the poster (4084.875 wide on reference), roughly 900–1000 tall.
**Naming:** `<variant>.svg`

In the SVG, replace literal hexes with role tokens so palettes can swap colors:
- `{{palette.anchor-dark}}`
- `{{palette.anchor-light}}`
- `{{palette.accent-primary}}`
- `{{palette.dominant}}`

## Current variants
- `piano-stripes.svg` — reference (vertical bars in alternating roles)
