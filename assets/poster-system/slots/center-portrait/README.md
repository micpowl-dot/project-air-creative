# Slot: `center/portrait`

**Purpose:** Square rounded headshot of the host/subject. The only slot that takes raster.
**Color role:** none (photo)
**Format:** PNG @2x, 1614 × 1607 on reference canvas. Pre-masked to the rounded-rect shape, OR raw photo + the mask applied at render.
**Naming:** `<first-last>.png` — e.g. `maya-smith.png`

## Mask
Open question in the spec: keep rounded-square only, or open up to `circle` / `arch` variants. Until decided, all portraits use the rounded-square mask from the reference frame.
