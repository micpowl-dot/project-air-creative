# Slot: `bottom-left/pattern-block`

**Purpose:** Tiled texture block that bleeds off the bottom-left corner.
**Color role:** `dominant` (darkened) — open question in spec whether to use `anchor-dark` instead.
**Format:** SVG, ~3300 wide × 1220 tall on reference canvas. Pattern can repeat infinitely; just export at the visible crop.
**Naming:** `<variant>.svg`

## Current variants
- `diamond-grid.svg` — reference (diamond/lattice pattern)

## Ideas for future variants
- `dot-grid` — regular dots
- `cross-hatch` — diagonal hatching
- `iso-cube` — isometric cubes
- `wave` — horizontal wave pattern
- `chevron` — chevron stripes
- `circuit` — circuit-trace lines (on-brand for AI)
