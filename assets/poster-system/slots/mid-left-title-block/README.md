# Slot: `mid-left/title-block`

**Purpose:** Session title, 2–4 lines, bold. Sits left of the ring badge.
**Color roles:** `anchor-dark` (main) + `accent-primary` (1–2 accented glyphs)
**Format:** Outlined SVG text OR live text + declared font.
**Naming:** kebab-case slug of the title — e.g. `n8n-workflows-in-action.svg`

## Accent rule
Tag 1 or 2 glyphs to render in `accent-primary`. Examples:
- "N**8**N Workflows in action" — the 8
- "**W**orkflows in action" — initial W
