# Progress — WIP Notes

> **Work in progress, not the canonical spec.** This folder is a rolling checkpoint of design-system work happening in Figma. Files here represent state-at-a-point-in-time and may be superseded by later versions or absorbed into other parts of the repo (e.g. `docs/brand-guidelines.md`) when finalized.

## What lives here

- **`YYYY-MM-DD-system-state.md`** — snapshot of the system as of that date. Designed to be pasted as the first message in a new Claude chat to bring it up to speed.
- **`YYYY-MM-DD-session-log.md`** — chronological log of what changed in that session, what was decided, and what's pending.

## How to use this folder

- **Picking up work in a new Claude chat:** open the most recent `*-system-state.md` and paste it (or reference its content) as your kickoff message. The chat will know the current Figma state, conventions, and gotchas without re-explaining.
- **Reviewing past work:** scan the `*-session-log.md` files chronologically.
- **Finalizing into the main repo:** when a piece of this becomes "the way it is," migrate it into `docs/brand-guidelines.md` or other canonical locations and drop the WIP note.

## What this is NOT

- ❌ The final brand spec — see `docs/brand-guidelines.md` for the canonical version
- ❌ A machine-readable manifest for automation — that would live at the repo root if/when built
- ❌ A polished design system doc — these are working notes
