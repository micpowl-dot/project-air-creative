## ▶️ Start a session (copy this into Claude Code)

> Load my AISOS. Pull the latest from the `aisos` repo, read the operating manual
> (`CLAUDE.md`) and `references/3ms-4cs-framework.md`, then wait for my command.
> Active project context is in this repo's `CONTEXT.md` if present.

On **desktop later:** clone once, then install the global brain so it loads
everywhere automatically:
```bash
git clone https://github.com/micpowl-dot/aisos.git
cp aisos/CLAUDE.md ~/.claude/CLAUDE.md          # merge if one exists
cp -R aisos/skills/* ~/.claude/skills/          # /onboard /audit /level-up everywhere
```

On **phone now:** I read and edit here in Obsidian. Skills run inside Claude Code
(web/desktop), not in the Obsidian app. Use this note to capture; run skills when at a machine or in Claude Code on the web.
